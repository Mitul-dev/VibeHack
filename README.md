# LoSpace

LoSpace is a **web-based platform** for discovering, booking, and
managing study and workspaces.\
It provides a fast, map-based experience to find nearby spaces, view
availability, and book time slots online.

------------------------------------------------------------------------

## Features

-   User authentication
-   Map-based workspace discovery
-   Search and filters
-   Real-time availability
-   Online booking with confirmation & QR code
-   Booking history
-   Reviews and ratings
-   Host listing management (MVP)
-   Admin moderation (MVP)

------------------------------------------------------------------------

## Tech Stack

-   Next.js (React 18)
-   TypeScript
-   Tailwind CSS
-   shadcn/ui
-   Supabase (PostgreSQL, Realtime, Storage)
-   Google Maps JavaScript SDK
-   Stripe & Razorpay (mock-ready)

------------------------------------------------------------------------

## Core Pages

-   Home (Map + List)
-   Search
-   Workspace Details
-   Booking Management
-   User Profile
-   Host Dashboard
-   Admin Panel

------------------------------------------------------------------------

## Policies

-   No refunds for cancellations, no-shows, or partial usage
